<objective>
Thread the D-Bus caller's unique bus name from the GDBus dispatch callback through to the C++ method
handler — the single load-bearing prerequisite for polkit-gating `save()` (Plan 06). ipcgull's
`function::operator()(args)` is args-in/args-out only; the `sender` string exists at
`gdbus_method_call` (server_gdbus.cpp:303) but is dropped. This plan adds a minimal, generic
`ipcgull::current_caller()` accessor (RESEARCH Option A) and wires the dispatcher to populate it.
It is intentionally ISOLATED from polkit so it can be verified on its own with a debug-log-the-sender
acceptance criterion before any authorization logic depends on it.

Purpose: ACCESS-02 foundation — make the caller identity reachable from a handler.
Output: `ipcgull::current_caller()` populated during dispatch, valid only inside a method call.
</objective>
