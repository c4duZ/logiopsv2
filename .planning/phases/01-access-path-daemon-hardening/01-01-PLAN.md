    `access-path.sh` (ACCESS-01): introspect with
    `busctl introspect --system pizza.pixl.LogiOps /pizza/pixl/logiops` then attempt a real
    method/property read as the current (non-root, logiops-group) user via `gdbus`/`busctl`.
    Assert exit 0 (not `org.freedesktop.DBus.Error.AccessDenied`). If `id -nG` lacks `logiops`,
    print "SKIP: not in logiops group (run: usermod -aG logiops $USER; re-login)" and exit 0.

    `polkit-deny.sh` (ACCESS-02 — the headline criterion): capture
    `sha256sum /etc/logid.cfg` into a var, invoke the `Save` method on
    `pizza.pixl.LogiOps` interface `pizza.pixl.LogiOps.Config` (object `/pizza/pixl/logiops`),
    instruct the operator to CANCEL the polkit prompt, then re-`sha256sum` and assert the two
    hashes are byte-identical AND a denied/WARN line appears in
    `journalctl -u logid --since "1 minute ago"`. Skip cleanly if `/etc/logid.cfg` is absent or no
    daemon is reachable.

    `hardening.sh` (ACCESS-03): assert via
    `systemctl show logid -p NoNewPrivileges,ProtectSystem,CapabilityBoundingSet,RestrictAddressFamilies`
    that `NoNewPrivileges=yes`, `ProtectSystem=strict`, `CapabilityBoundingSet=` is empty, and
    `RestrictAddressFamilies` contains `AF_UNIX` and `AF_NETLINK`; then print the last line of
    `systemd-analyze security logid` (the exposure score). Skip cleanly if the unit isn't installed.
  </action>
