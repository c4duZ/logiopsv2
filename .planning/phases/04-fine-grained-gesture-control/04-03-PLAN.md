## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Tampering | QML mode/direction strings | mitigate | QML passes the locked plain-language LABELS to `gestureModel.setMode`; the model maps them through its allowlist — QML never emits raw daemon `type` strings, so an unmapped label is rejected in C++ (Plan 02), not sent. |
| T-04-03-02 | DoS | SetAction→SetGesture ordering | mitigate | The category issues `SetAction("Gestures")` before opening the builder so the GestureAction (and its gestures map, lazy-inited by Plan 01) exists before any SetGesture — no bad_optional_access. |
| T-04-03-03 | Elevation of privilege | Save path | accept (inherited) | No new Save path; persistence reuses the Phase 1/3 polkit-gated `.Config.Save`. Live-apply is group-`logiops`-gated as designed (ACCESS-01). |
| T-04-03-04 | Information disclosure | preview/readout copy | accept | Only plain-language copy and the user's own choices are shown; no daemon internals or HID++ units surfaced (UI-SPEC rule, asserted in Plan 02 model tests). |
