  <read_first>.gitignore (LogiOptionsPlus ignored); src/logiops-gui/logiops-gui.desktop (Plan 01, already scrubbed); src/logid/ipc_defs.h (SERVICE_ROOT_NAME = pizza.pixl.LogiOps)</read_first>

  <action>
Create `packaging/audit-no-proprietary-assets.sh` (sh/bash, `set -euo pipefail`,
chmod +x). It takes one or more built `.deb` paths as arguments and:
  1. For each .deb, list contents with `dpkg-deb -c "$deb"` and the control with
     `dpkg-deb -e`/`dpkg-deb -f`.
  2. FAIL (exit 1, print the offending line) if the file list contains ANY of these
     case-insensitive patterns: `LogiOptionsPlus`, `app.asar`, `options-plus`, `intel/options`,
     `/extract`, `/scratch`, `devices_.*\.json`, `predefined_.*\.json`, `applications\.json`.
  3. Extract the package data (`dpkg-deb -x "$deb" tmpdir`) and grep shipped text files
     (.desktop, copyright, any shipped .json/.txt) for the marks
     `Logi Options+`, `Options Plus`, and standalone `Options+` → FAIL on match.
     (Do NOT fail on the word "Logitech" alone — the trademark notice / device-name strings
     legitimately reference Logitech; the gate is about proprietary ASSETS and the product
     name, per the hybrid/reference-only boundary. Allow "Logitech" as a plain noun.)
  4. On clean pass, print `AUDIT PASS: no proprietary assets in <deb>` and exit 0.
This script is the BLOCKING legal acceptance criterion — its non-zero exit must fail CI.

Create `packaging/smoke-dbus-handshake.sh` (sh/bash, `set -u`, chmod +x), mirroring the
Phase 1/2 graceful-skip smoke pattern:
  1. If there is no system D-Bus (`! test -S /run/dbus/system_bus_socket` and `dbus-send`
     to the bus fails) → print `SKIP: no system bus` and exit 0.
  2. Try to reach the daemon as the current (non-root) user:
     `dbus-send --system --print-reply --dest=pizza.pixl.LogiOps /pizza/pixl/logiops
      org.freedesktop.DBus.Introspectable.Introspect` (or busctl introspect).
  3. If the name has no owner (daemon not running — expected in a deviceless CI container)
     → print `SKIP: daemon not running / no device` and exit 0.
  4. If the daemon IS reachable but the call returns an access-denied / permission error
     → FAIL (exit 1): that is the real handshake regression we guard.
  5. If the introspect succeeds → print `HANDSHAKE OK` and exit 0.
The point: on a real fresh-install VM with the daemon up, a logiops-group user introspecting
  succeeds; CI without a device exercises build/install but skips the live call gracefully.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| built .deb → end users | the package list/content is what actually ships |
| fresh install → non-root user | the user reaches the root daemon over the system D-Bus |
| CI runner → published artifact | a green pipeline gates release |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Information disclosure (LEGAL) | packaged .deb contents | mitigate | audit-no-proprietary-assets.sh inspects `dpkg-deb -c` of the BUILT .deb (what ships, not just source) for proprietary asset paths/names + product-name marks; non-zero exit is a BLOCKING CI failure; checkpoint step 3 proves the audit actually fails on a planted asset |
| T-09-07 | Elevation | fresh-install non-root D-Bus reach | mitigate | smoke-dbus-handshake.sh fails on a real access-denied (the Phase 1 group-policy regression), confirming the documented `usermod -aG logiops` path is the only widening — no anonymous access |
| T-09-08 | Tampering | upgrade/purge maintainer scripts | mitigate | CI exercises install→reinstall(upgrade)→purge end to end; a non-idempotent postinst or a purge that errors fails the job |
| T-09-09 | Denial of service | CI false-green (audit no-ops) | mitigate | checkpoint step 3 plants an `app.asar` path and requires the audit to fail, proving the gate is live |
| T-09-10 | Spoofing | GUI run against wrong daemon | mitigate | CI asserts the versioned `logiops-daemon (>=` Depends in the GUI .deb (re-assert PKG-01) |
