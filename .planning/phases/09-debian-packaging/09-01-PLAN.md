<objective>
Create the Debian source-packaging tree (`debian/`) that builds the project into TWO binary
packages from the existing CMake build:
  - `logiops-daemon` — the `logid` binary plus its D-Bus system policy
    (`pizza.pixl.LogiOps.conf`), polkit action (`pizza.pixl.logiops.policy`), and the
    `logid.service` systemd unit.
  - `logiops-gui` — the Qt 6 `logiops-gui` binary plus a `.desktop` launcher, declaring a
    **versioned dependency on `logiops-daemon`** so the daemon is never assumed pre-installed.

Purpose: Satisfy PKG-01 — the app installs on Debian/Ubuntu as a package that depends on the
`logid` daemon and ships its policy, polkit action, and systemd unit. This enforces the
GUI↔daemon version contract decided in Phase 1 (a GUI that talks to a daemon over a specific
D-Bus/polkit surface must pull in a compatible daemon).

Output: A complete `debian/` directory plus a `.desktop` file, such that
`dpkg-buildpackage -us -uc -b` produces both `.deb` files. (CI integration + the
install/upgrade/purge + legal-asset audit live in Plan 02.)
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package install → root | dpkg runs maintainer scripts (postinst/postrm) as root |
| .deb contents → distribution | the built package is shipped/published to users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Elevation | debian/logiops-daemon.postinst | mitigate | `set -e`; only create a *system* group (`addgroup --system`, no shell, no login); guard group ops with `getent`; never chmod/chown beyond the group; defer service mgmt to dh_installsystemd generated snippets |
| T-09-02 | Tampering | debian/logiops-daemon.postrm purge | mitigate | guard group removal so purge cannot fail; do NOT delete user config (/etc/logid.cfg) on purge — treat as user data, no destructive removal |
| T-09-03 | Information disclosure | packaged tree (LEGAL) | mitigate | package only the CMake-installed /usr tree via explicit .install globs; never glob the source root, so gitignored `LogiOptionsPlus/` and any extract scratch cannot enter the .deb (Plan 02 adds the blocking audit) |
| T-09-04 | Spoofing | GUI↔daemon version skew | mitigate | versioned `Depends: logiops-daemon (>= ${source:Version})` ensures the GUI never runs against an incompatible daemon D-Bus/polkit surface |
| T-09-05 | Denial of service | systemd unit on fresh install | accept | daemon runs as root with Phase-1 hardening; if no Logitech device present it idles — acceptable, standard for hardware daemons |
</threat_model>
