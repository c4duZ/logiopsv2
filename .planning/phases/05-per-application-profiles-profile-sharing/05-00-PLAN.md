Match engine (Plan 02 will provide a free function or static method, daemon-free,
no Qt, no D-Bus — pure rule evaluation so it can be unit-tested standalone):

```cpp
// A single app-match rule (PROF-03). `field` selects what to match against the
// focused window; `pattern` is a case-insensitive substring/glob; profile is the
// profile name to activate on match. Order in the rule list = precedence.
struct AppMatchRule {
    enum class Field { WindowClass, Executable };
    Field field;
    std::string pattern;      // matched case-insensitively
    std::string profile;      // target profile name
};

// The observed foreground window at a point in time (filled by the FocusWatcher
// in Plan 01; the engine only sees these two strings + nothing else).
struct FocusInfo {
    std::string windowClass;  // X11 WM_CLASS / Wayland app_id (may be empty)
    std::string executable;   // basename of the process exe (may be empty)
};

// Returns the profile name of the FIRST matching rule in `rules`, or
// `defaultProfile` if none match. Empty FocusInfo fields never match a
// non-empty pattern. Matching is case-insensitive substring.
std::string resolveProfile(const std::vector<AppMatchRule>& rules,
                           const FocusInfo& focus,
                           const std::string& defaultProfile);
```

Profile IO (Plan 03 will provide export/import as a libconfig profile block wrapped
in a small versioned envelope, daemon-free so it is unit-testable standalone):

```cpp
// Serialize one named profile (a libconfig Profile setting subtree) to a
// self-contained shareable string. import parses it back. A round-trip MUST
// preserve the profile name + every setting value. import MUST reject a payload
// whose top-level "logiops_profile_version" is absent or unsupported (throws).
std::string exportProfile(const std::string& profileName,
                          const libconfig::Setting& profileBlock);
// Parses an exported payload; throws on bad envelope. outName receives the name.
libconfig::Config importProfile(const std::string& payload, std::string& outName);
```
