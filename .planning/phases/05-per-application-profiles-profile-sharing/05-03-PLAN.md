<!-- The export/import contract (matches the Plan-00 RED test). Daemon-free, libconfig-only. -->
```cpp
// Wraps ONE profile block in a versioned envelope so it is a self-contained,
// validatable shareable file. Round-trip preserves name + every setting value.
std::string exportProfile(const std::string& profileName,
                          const libconfig::Setting& profileBlock);

// Parses an exported payload. Throws std::runtime_error if the top-level
// "logiops_profile_version" is missing or unsupported. outName receives the name.
libconfig::Config importProfile(const std::string& payload, std::string& outName);
```
Envelope shape (libconfig text):
  logiops_profile_version = 1;
  name = "Browsing";
  profile : { /* the exact Profile block: buttons, dpi, smartshift, ... */ };
</interfaces>
