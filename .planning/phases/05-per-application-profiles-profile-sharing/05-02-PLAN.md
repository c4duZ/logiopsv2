<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compositor → helper | window class/app_id/exe are untrusted strings, used only as match keys + as the SetProfile arg |
| helper → daemon | helper (non-root) calls the already-authorized .Device.SetProfile over D-Bus |
| rule file → helper | $XDG_CONFIG_HOME JSON is user-controlled but parsed defensively |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Tampering | X11/Wayland property buffers | mitigate | Length-check every property reply before indexing (WM_CLASS, _NET_WM_PID); never pass window strings as a printf format |
| T-05-02-02 | Injection | matched string → SetProfile arg | mitigate | SetProfile takes a profile NAME from the rule (user-authored), not the raw window string; window string only selects which rule fires |
| T-05-02-03 | DoS | rapid focus flips → SetProfile storm | mitigate | Debounce focus changes; only call SetProfile when the resolved profile actually changes |
| T-05-02-04 | Elevation | helper switching profiles | accept | Helper is non-root and only invokes the already-group-authorized SetProfile (ACCESS-01); no new privilege surface |
</threat_model>
