<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GUI (non-root) -> root logid daemon over D-Bus | Action assignment + key/host strings cross into the root daemon |
| User keyboard input -> key-capture -> SetKeys | Captured keys become evdev names sent to the daemon |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-02-01 | Tampering | malformed/format-string-like key name reaches the daemon via SetKeys | mitigate | SetKeys takes a typed `as`; only KeyNameMapper KEY_* names are emitted (unknown->dropped); daemon logger "%s"-hardened (Phase 1) |
| T-3-02-02 | Denial of Service | non-numeric/out-of-range host string -> daemon std::stoi throws unhandled | mitigate | ButtonsModel.setChangeHost validates "1".."N"/"next"/"prev" BEFORE the D-Bus call (asserted in the model test) |
| T-3-02-03 | Tampering | SetAction on a non-remappable button -> daemon throws invalid_argument | mitigate | Hotspot gated on the Remappable property; non-remappable shown disabled, never sends SetAction |
| T-3-02-04 | Denial of Service | calling Action.<type> setter before SetAction created it -> UnknownMethod loop | mitigate | Strict two-step ordering via QDBusPendingCallWatcher (RESEARCH Pitfall 2; ordering asserted in test) |
| T-3-02-05 | Elevation of Privilege | GUI tries to write config to disk directly to apply a reassign | accept | Reassign is a live D-Bus setter only; persistence is the polkit-gated Save() (Plan 04); GUI never touches /etc/logid.cfg |
</threat_model>
