## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GUI (non-root) -> root logid daemon over D-Bus | DPI/SmartShift/hires/thumbwheel setters cross into the root daemon |
| Hand-edited cfg -> save() (if option-a adds a schema field) | New labels field must round-trip without loss |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-03-01 | Tampering | out-of-range DPI value sent to SetDPI | mitigate | Slider bounded by device min/max; values clamp to [dpiMin,dpiMax] before emit; daemon also snaps via getClosestDPI (defense in depth) |
| T-3-03-02 | Denial of Service | per-pixel slider drag floods the daemon with SetDPI calls | mitigate | Setter fires on onMoved/onPressedChanged only, not per-pixel (RESEARCH; asserted by code shape) |
| T-3-03-03 | Tampering | option-a labels field breaks save() round-trip (silent value loss) | mitigate | Plan 00 round-trip test EXTENDED to assert labels survive; re-run before phase gate |
| T-3-03-04 | Tampering | calling a setter on an absent feature interface -> daemon error | mitigate | Every section gated on the introspected capability flag; absent -> section hidden, no calls issued |
</threat_model>
