## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GUI (non-root) -> root logid daemon over D-Bus | Introspect + Get* reads cross into the root daemon |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01-01 | Information Disclosure | Introspect leaks interface layout to a non-root user | accept | The interface set is already readable to the `logiops` group by Phase 1 policy; it is configuration metadata, not a secret |
| T-3-01-02 | Denial of Service | a slow/asleep device blocks the UI thread during capability reads | mitigate | All DeviceController reads use async QDBusPendingCallWatcher (RESEARCH Pitfall 4 / Phase 2 precedent); QML never blocks |
| T-3-01-03 | Tampering | controller assumes an interface present and calls a missing method -> daemon error | mitigate | Gate every feature proxy build on the introspected present-set; treat UnknownInterface as absent |
</threat_model>
