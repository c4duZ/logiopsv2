<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GUI (non-root) -> root logid daemon over D-Bus | Untrusted client input crosses into a root process; widened to the `logiops` group in Phase 1 |
| Config file on disk -> daemon in-memory tree | A hand-edited cfg (possibly malformed) is parsed by the round-trip path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-00-01 | Tampering | save() round-trip silently drops a device block or value | mitigate | The phase3_save_roundtrip test ASSERTS device-block count + all values preserved; CI-gated before any persistence UI ships (CONF-01) |
| T-3-00-02 | Denial of Service | schema-unknown key in cfg crashes save() (unhandled parse) | mitigate | phase3_save_unknownkey test proves no crash; document the drop in Save copy (handled in Plan 04) |
| T-3-00-03 | Tampering | KeyNameMapper emits a garbage/format-string-like key name the daemon mishandles | mitigate | Mapper returns only daemon-accepted KEY_* names or empty; daemon logger already "%s"-hardened (Phase 1, CONCERNS #5); unknown keys map to empty, never a guessed token |
| T-3-00-04 | Elevation of Privilege | a test reaches around the polkit gate by calling save() write path directly | accept | Test exercises config::set serialization on a TEMP file it owns, never /etc/logid.cfg and never the polkit-gated Save() method; no privilege crosses |
</threat_model>
