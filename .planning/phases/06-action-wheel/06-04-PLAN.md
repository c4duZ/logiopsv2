<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon → GUI overlay (D-Bus signal) | ActiveSlice/visibility flows from the root daemon to the unprivileged overlay; the overlay only reads it to draw. |
| overlay window → compositor | The overlay is an always-on-top, click-through user-session window. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-01 | I (Info disclosure) | always-on-top overlay window | accept | Overlay draws only the user's own configured slice labels; shows nothing sensitive; user-session scope. |
| T-06-04-02 | D (DoS) | overlay show/hide on rapid ActiveSlice changes | mitigate | Debounce/coalesce ActiveSlice updates on the GUI timer; never block the daemon (read-only signal). |
| T-06-04-03 | E (Elevation) | click-through window must run as the session user | mitigate | Overlay is part of the unprivileged GUI; it never runs as root and never calls a privileged D-Bus method (only reads ActiveSlice). |
</threat_model>
