<objective>
Fix Bug A: a gesture configured LIVE over D-Bus (the GUI's two-step on a non-cfg
button) lands successfully — SetGesture, SetAction("Keypress"), SetKeys, SetThreshold
all return success — yet the gesture engages but never fires, and the gesture node's
Introspect omits the just-created Action.Keypress interface. Root cause (debug file +
ipcgull read): a node holds only a `weak_ptr` to each interface (`node::_interfaces` is
`std::map<std::string, std::weak_ptr<interface>>`, src/ipcgull/src/include/ipcgull/node.h:37);
an interface stays introspectable + dispatched ONLY while some owner holds a strong
`shared_ptr` to it. The working cfg-load path keeps the child action alive via the
gesture's `_action` member; the live `setAction` path must do the EXACTLY equivalent
wiring so the new action is (a) stored as the gesture's dispatched `_action` AND (b)
alive so its weak entry in `_node->_interfaces` resolves (introspectable). Converge the
live path onto the proven cfg-load path, confirm SetThreshold/SetInterval mutate the
live dispatched gesture, and resolve the ReleaseGesture/ThresholdGesture interface-name
collision so it cannot mask the intended type.

Purpose: GEST-05 — a GUI-built gesture actually fires on hardware; GEST-02/03 —
granularity set from the GUI changes on-hardware behavior.
Output: Corrected daemon gesture child-action wiring + a daemon CTest pinning the
introspectable-and-dispatched contract.

```cpp
// A node keeps only a WEAK reference to each registered interface:
std::map<std::string, std::weak_ptr<interface>> _interfaces;
// make_interface<T>(...) builds the shared_ptr, registers it with the server,
// sets ptr->_owner = _self, stores the WEAK ptr in _interfaces, and RETURNS the
// shared_ptr. If the caller does not keep that shared_ptr alive, ~interface runs
// -> owner->drop_interface(name) -> the interface vanishes from Introspect/dispatch.
template<typename T, typename... Args>
std::shared_ptr<T> make_interface(Args&&... args);  // throws "duplicate interface" if name present
bool drop_interface(const std::string& name);
std::shared_ptr<node> make_child(const std::string& name) const;  // ALWAYS a NEW node
```
