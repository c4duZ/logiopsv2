<objective>
Add the daemon-side composite Smart Action: an ordered list of Keystroke / Text /
Delay / Launch steps bound to one button, firing in order with inter-step delays
scheduled on the worker pool (MACRO-01). Launch-app / open-URL steps are NEVER run
by the root daemon — the daemon only EMITS a D-Bus request; the non-root
user-session helper (the `src/logiops-session-helper/` module that Phase 5
introduces for focus-watching) is EXTENDED here with a real RequestLaunch handler
that opens the app/URL in the user session (MACRO-02). Phase 7 owns and ships that
launch handler so MACRO-02 is complete end-to-end, not a dangling contract.

Purpose: This is the core feature. The composite action slots into the existing
Action/makeAction/schema machinery exactly like KeypressAction, reusing the worker
pool's run_task_after for delays (locked architecture). The root-never-spawns rule
is a hard security boundary, not a convenience: the privileged daemon emits an
opaque request and the unprivileged, per-user helper is the only thing that ever
exec's anything.
Output: SmartAction action + config schema + factory wiring (daemon side); a real
RequestLaunch handler added to `src/logiops-session-helper/` (helper side) plus the
documented IPC contract. Daemon stays -Werror clean.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| root daemon → user session | A Launch/URL step must execute as the user, never as root |
| D-Bus client → SmartAction | step indices/payloads from an unprivileged caller are untrusted |
| HID event thread → worker pool | delays must not block the real-time HID/event thread |
| daemon request → helper LaunchHandler | the target string the helper receives is untrusted; it must never reach a shell |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-01-01 | Elevation of Privilege | Launch step (daemon) | mitigate | Daemon NEVER fork/exec/system()/xdg-open; Launch routes to the non-root session helper over the documented D-Bus contract (MACRO-02 hard boundary) |
| T-7-01-02 | Tampering | RemoveStep/MoveStep/SetStepPayload | mitigate | Bounds-check every index against the step-list size before access; reject out-of-range with no mutation |
| T-7-01-03 | Denial of Service | press() sequencer | mitigate | Delays scheduled via run_task_after on the worker pool — never sleep on the HID/event thread; clamp durationMs to a sane non-negative max |
| T-7-01-04 | Tampering | Text/Keypress step | mitigate | Map characters/keys via InputDevice::toKeyCode and skip-with-WARN on invalid codes (mirrors KeypressAction::_setConfig); never index raw |
| T-7-01-05 | Injection | LaunchHandler target (helper) | mitigate | Helper passes program+args as an argv LIST to QProcess (never a shell command string); URLs parsed as QUrl before openUrl; kind allowlisted to App|URL; empty target rejected |
| T-7-01-06 | Elevation of Privilege | LaunchHandler bus exposure | accept | Handler is registered on the session bus only and runs as the unprivileged user; it confers no privilege beyond what the user already has, documented in IPC_CONTRACT.md |
</threat_model>
