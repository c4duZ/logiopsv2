pizza.pixl.LogiOps.Action.SmartAction (at the button's action node):
  GetSteps, AddStep(kind, payload), RemoveStep(index), MoveStep(from,to),
  SetStepPayload(index, payload).  kind is one of Keypress / Text / Delay / Launch.

Two-step dispatch (mirrors ButtonsModel/GestureModel):
  Step 1: ButtonsModel-style SetAction("SmartAction") on the button to create the
          Action.SmartAction interface. Step 2 (chained after the reply): AddStep
          etc. on the now-existing Action.SmartAction interface at the action node.
  Funnel both legs through virtual performSetAction()/performStepCall() hooks so
  the phase7 recording-subclass asserts order+args with no live bus.

SmartActionModel (this plan):
  QAbstractListModel; roles: kind, summary, payload, isDelegated (Launch is true).
  Q_INVOKABLE: addStep(kind), removeStep(row), moveStep(from,to),
  setStepPayload(row, payload). setConfigState(ConfigState*) for dirty-marking.
  Live ctor (buttonPath, bus); test ctor (no bus) like GestureModel.
</interfaces>
