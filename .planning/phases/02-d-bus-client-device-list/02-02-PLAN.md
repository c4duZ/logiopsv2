The 0x1000 `GetBatteryLevelStatus` (function 0) response is documented as: `param[0]` = battery discharge level (percentage 0..100), `param[1]` = next discharge level, `param[2]` = battery status enum (0=discharging, 1=recharging, 2=almost full, 3=full/charge complete, 4=slow recharge, 5=invalid battery, 6=thermal error). Create `src/logid/backend/hidpp20/features/BatteryStatus.h` mirroring `WirelessDeviceStatus.h`:
```cpp
#ifndef LOGID_BACKEND_HIDPP20_FEATURE_BATTERYSTATUS_H
#define LOGID_BACKEND_HIDPP20_FEATURE_BATTERYSTATUS_H
// ... GPL header copied from WirelessDeviceStatus.h ...
namespace logid::backend::hidpp20 {
    class BatteryStatus : public Feature {
    public:
        static constexpr uint16_t ID = FeatureID::BATTERY_STATUS; // 0x1000
        [[nodiscard]] uint16_t getID() final { return ID; }
        enum Function { GetBatteryLevelStatus = 0 };
        enum Event : uint8_t { BatteryStatusBroadcast = 0 };
        struct Status { uint8_t percentage; bool charging; bool known; };
        explicit BatteryStatus(Device* dev);
        Status getStatus();                                       // calls function 0
        static Status decodeStatus(const hidpp::Report& report);  // PURE, unit-tested
    };
}
#endif
```

Create `src/logid/backend/hidpp20/features/BatteryStatus.cpp`:
- ctor: `BatteryStatus(Device* dev) : Feature(dev, ID) {}` (Feature base throws UnsupportedFeature if 0x1000 index unresolved — same as other wrappers).
- `decodeStatus(report)`: LENGTH-CHECK FIRST — derive the available param count from the report (mirror how Report exposes payload size; if fewer than 3 params, return `{0,false,false}`).
